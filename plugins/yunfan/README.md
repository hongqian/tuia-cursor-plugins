# 云帆质量管理插件

通过云帆 MCP 在 Cursor 中查询和分析项目质量数据。

## 功能

- 查询问题单列表，支持按人员、时间、状态、类型、严重程度等筛选
- 查看问题单详情及操作记录
- 问题单统计概览
- 线上答疑问题查询与统计

## 包含组件

- **MCP Server**: `yunfan-mcp` — 连接云帆质量管理系统
- **Skill**: 云帆质量查询指南 — 指导 Agent 正确使用云帆 MCP 工具

## 使用示例

安装插件后，在 Cursor Agent 中直接提问即可：

- "查一下张三的 BUG"
- "看看阻塞级的待处理问题"
- "统计一下当前的质量状况"
