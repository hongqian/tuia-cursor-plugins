# 百川需求管理插件

通过百川 MCP 在 Cursor 中查询和分析项目迭代需求。

## 功能

- 查询需求列表，支持按人员、时间、阶段、版本等多维度筛选
- 查看单条需求详情
- 统计概览（阶段/优先级/人员分布）

## 包含组件

- **MCP Server**: `baichuan-mcp` — 连接百川需求管理系统
- **Skill**: 百川需求查询指南 — 指导 Agent 正确使用百川 MCP 工具

## 使用示例

安装插件后，在 Cursor Agent 中直接提问即可：

- "查一下张三本周的需求"
- "看看 P0 需求有哪些"
- "统计一下当前迭代的需求分布"
